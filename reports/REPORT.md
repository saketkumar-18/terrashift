# TerraShift — Final Report

**Project:** Satellite Change Detection over Indian change hotspots (2019 → 2026)
**Stack:** Sentinel-2 L2A + ESA WorldCover 2021 + RandomForest + FastAPI + MapLibre
**Live:** https://terrashift-in.vercel.app · **Repo:** github.com/saketkumar-18/terrashift

## 1. Objective

Detect and quantify land-cover change between dry-season 2019 and
dry-season 2026 over three documented Indian change hotspots, with honest
spatially-validated accuracy, per-patch geodesic areas, and a public
interactive map — end to end on free data and free hosting.

| AOI | Focus | Bbox (W,S,E,N) |
|---|---|---|
| ncr-gurugram | urban growth (Dwarka Expy / Manesar belt) | 76.85, 28.15, 77.25, 28.55 |
| papum-pare | forest loss (Itanagar foothills) | 93.60, 26.85, 94.00, 27.25 |
| jharia | open-cast mining expansion | 86.20, 23.65, 86.50, 23.95 |

- Epochs are Jan–Mar dry-season windows; scene filter `eo:cloud_cover < 30`.
- Per epoch up to 12 scenes per AOI; scenes with < 10% usable (SCL-good)
  AOI pixels are dropped. Each scene contributes only SCL-good pixels
  (classes 2,4,5,6,7); clouds/cirrus/shadow/snow/saturated excluded.
- 2019/2021 read from collection `sentinel-2-l2a`; 2026 from
  `sentinel-2-c1-l2a` (collection-1 reprocessing — same L2A surface
  reflectance, continuing archive).
- Scene IDs per composite are stored inside each npz (`scene_ids`).

## 3. Method

### 3.1 Shared analysis grid
One fixed EPSG:4326 grid at 1/1200° (~90 m N-S) per AOI. 1/1200° is
exactly 10× the WorldCover 10 m pixel (1/12000°), and every AOI bbox is
a 0.05° multiple, so all window offsets are exact integers — band reads
and label aggregation are pure array reshapes, no per-pixel geocoding.

### 3.2 Composites
Per scene: AOI window read via WarpedVRT (UTM → EPSG:4326 grid,
bilinear for reflectance, nearest for SCL) — windowed ranged reads
against the COG, never full-scene downloads. Reflectance = DN × scale +
offset with nodata/≤0/∈[0,1.6]-range guards → NaN. Per epoch: per-pixel
median over scenes + observation count; cells with < 3 obs excluded.
Features (8): green, red, NIR, SWIR16, NDVI, NDBI, MNDWI, brightness.

### 3.3 Labels
WorldCover 2021 dominant class per 90 m cell via 10×10 block counts;
5 classes: forest, grass_agri, bare, built, water (shrub/snow/wetland/
moss/mangrove excluded). Training label kept only when purity ≥ 0.70.
Label year (2021) matches the training epoch (2021 composite).

### 3.4 Model
RandomForest (300 trees, max_depth 14, min_samples_leaf 3,
class_weight balanced_subsample) on 8 features. Validation:
GroupKFold(5) on 5×5-cell spatial blocks (450 m) — train folds
class-balanced by subsampling, test folds left at natural priors.
Metrics: overall accuracy, macro-F1, Cohen's κ, per-class recall.

### 3.5 Change products
Classify 2019 and 2026 composites cell-wise (invalid → −1). Transition
grid `from*5+to`, valid only where both epochs observed. Products are
disjoint (from,to) sets:

| Product | Transitions |
|---|---|
| urban_growth | grass/bare → built |
| forest_loss | forest → grass/bare/built |
| bare_expansion | grass → bare (mining/excavation) |
| new_water | any land → water |
| water_loss | water → any land |

Cells vectorized per product, merged, geodesic areas via pyproj.Geod;
patches < 6 ha dropped. Product areas cannot double-count.

## 5. Limitations

1. **90 m grid** — sub-hectare change and linear features < ~3 cells
   wide are invisible. Patch minimum 6 ha removes small-change signals.
2. **Label-year mismatch** — labels are WorldCover 2021; the 2019 and
   2026 epochs stretch label fidelity at rapidly changing pixels.
   The 0.70 purity filter mitigates, not eliminates, this.
3. **Optical only** — monsoon/haze gaps become NaN cells excluded from
   products (n_obs tracks this); no SAR fallback.
4. **Per-cell RF** — no spatial context; median composites + 6 ha
   minimum patches suppress salt-and-pepper but cannot eliminate it.
5. **Scene availability 2026** — c1 collection coverage for Jan–Mar
   2026 is thinner; if an epoch drops below 3 usable scenes the AOI is
   skipped rather than published with unstable stats.
6. **WorldCover class mixing** — cropland vs grassland are merged
   (grass_agri) since 10 m labels are unreliable for that split; bare
   vs built confusion in bright industrial roofs remains the hardest
   pair (visible in per-class recall).

## 6. Reproducibility chain

```
scripts/run_pipeline.py          # stages 1-5, idempotent, disk-cached
  stage 1  lib/stac_io.build_composite     (STAC → windowed reads → median npz)
  stage 2  lib/labels.build_labels         (WorldCover → purity-filtered labels npz)
  stage 3  lib/model.train_eval             (spatial CV → rf_landcover.joblib + metrics.json)
  stage 4  lib/model.predict_epoch         (2019/2026 → pred npz per epoch)
  stage 5  lib/change.*                     (transitions → GeoJSON → api/data/)
```

- Scene windows cached in `data/cache/` (npz); reruns skip fetched data.
- All randomness fixed (RF random_state=42, subsampling seed=42).
- `python -m pytest tests/ -q` — 15 offline tests (grid, features,
  cloud-mask compositing, label purity/cross-tile, model round-trip,
  transition codes, patch area filter, API endpoints).
- CI: GitHub Actions runs the suite on every push/PR.

## 7. Ethics

See `ETHICS.md` — aggregate open data only, no personal data at 90 m,
change ≠ illegality, spatial-CV honest metrics, documented limitations,
